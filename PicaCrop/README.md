# 📸 PicaCrop —— 图片拼接与裁剪工具

PicaCrop 是一款轻量级的图片拼接与精细裁剪桌面工具，支持多图拼接、分块裁剪、涂鸦标注与悬浮预览。


## 📌 更新记录（v2.0.0）

- **Picsew 式自动对齐**：加载连续截图后自动检测重叠区域与状态栏，一键无缝去重
- **按目标体积导出**：低 ≈1MB / 中 ≈5MB / 高 ≈10MB，自动逼近；支持 PNG / JPG / WebP / PDF
- **WebP 压缩**：同体积清晰度约为 PNG 的 3 倍以上，自定义导出可选
- **快速导出**：一键直出，可设置导出路径（设置后直接保存，不再弹窗）
- **拖入文件夹**：直接把文件夹拖进窗口即可载入图片
- **全新界面**：微信/飞书风格重构，深色模式、圆角开关、抗锯齿绘制
- **高分屏适配**：Per-Monitor DPI 感知，125%/150%/200% 缩放下清晰不发虚

## ✨ 功能

### 🧩 拼接（Picsew 式自动对齐）
- 横向 / 竖向拼接
- **自动重叠检测**：加载多张连续截图后，后台自动识别相邻截图的重叠区域与状态栏，一键对齐去重（算法类似 Picsew）
- 顶部「自动对齐」按钮可随时重新对齐
- 手动微调：拖拽裁剪线 / 拼接线，支持完全隐藏或删除多余分块

### ✂️ 精准裁剪
- 裁剪线固定，仅两侧变化
- 分块操作：右键删除 / 左旋 90° / 右旋 90°
- 添加裁剪线分割当前图

### 🖊️ 涂鸦标注
- 矩形 / 圆形 / 线条 / 箭头 / 文字
- Shift 约束、颜色 + 粗细、撤销 / 确认

### 📌 置顶预览
- 独立悬浮窗口、透明度调节、窗口置顶

### 📤 按目标体积导出
- PNG / JPG / WebP / PDF，三档体积：**低 ≈1 MB / 中 ≈5 MB / 高 ≈10 MB**
- **WebP**：压缩效率最高的成熟格式（同体积清晰度约为 PNG 的 3 倍以上），快速导出默认 WebP
- 自动逼近目标大小：JPG 调质量、超限再降分辨率；PNG/PDF 超限自动降分辨率
- 内容很小（如少量小图）时不会强行撑大，文件更小为佳
- 先按目标体积估算渲染比例，再后台渲染压缩，导出快、界面不卡顿
- 导出确认时弹出保存位置，可自选文件夹

## 🚀 运行

```bash
pip install pillow
python PicaCrop.py
```

> 自动重叠检测推荐安装 numpy（可选）：`pip install numpy`，检测更快更准；未安装时仍可正常使用，只是自动对齐会退化为粗略模式。

## 🖥️ 界面
- 首页：选择目录 → 按顺序选图（再次点击可取消选中）→ 竖向 / 横向拼接
- 编辑区：滚轮缩放 | Tab 预览 | Ctrl+左键拖动画布 | 右键块区域菜单
- 缩略图圆角卡片 + 悬停高亮，选图列表流畅不卡顿（增量渲染）

## 🖥️ 高分屏适配
- 自动声明 Windows DPI 感知（Per-Monitor V2），125% / 150% / 200% 缩放下文字与界面清晰不发虚
- 字体、窗口、缩略图、边距等按系统缩放比例自适应

## 📌 说明
- 自动对齐仅在检测到可信重叠时生效；不相关的图片不会被误裁剪。
- 历史记录支持撤销（Ctrl+Z 见编辑区菜单）。
